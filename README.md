# Book of Answers

A static "Book of Answers" website with:

- floating magical book animation
- Chinese answers in the top display panel
- English answers on the book pages
- light and dark theme toggle
- mobile-friendly layout

## Live Site

https://bryanlwb.github.io/book-of-answers/

## Run Locally

Open `index.html` in a browser.

## Files

- `index.html` - page structure
- `style.css` - visuals, layout, animation, themes
- `script.js` - answers, theme switching, interactions
- `assets/` - SVG cover and page textures
